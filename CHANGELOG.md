# Changelog

## 0.4.0

- Added modular date, filter, monitoring, document, requirements, and scoring services.
- Added isolated `stateStoreId` monitoring with stable tender IDs, fingerprints, first/last seen timestamps, status and closing-date change alerts.
- Added evidence-backed requirement extraction, optional trusted public PDF analysis, bid-security fields, site-visit/pre-bid detection, and readiness checklists.
- Added explainable opportunity and risk factors with Zimbabwe timezone-aware deadlines.
- Added reliable row deduplication, page-transition verification, bounded concurrent saves, and accurate run summaries.
- Corrected the Apify dataset schema structure and added five output views.
- Replaced the live-network test with deterministic tests and documented local smoke testing.

## 0.3.0

- Added initial named-store tender memory, new-only mode, and basic status-change alerts.
- Added initial document links, requirement signals, and opportunity/risk scoring.

## 0.2.0

- Added pagination, detail-page enrichment, buyer/category/status filters, days-remaining filters, business categories, and document-link cleanup.
